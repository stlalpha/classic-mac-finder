# Third-party assets

The `MacOS9Folder`, `MacOS9Document`, and `MacOS9Application` image sets are
64-pixel PNG conversions of icons from [bearz314/MacOS9-icons](https://github.com/bearz314/MacOS9-icons).
The source repository includes an MIT License, reproduced in
`MacOS9-icons-LICENSE.txt`. Its README says the source icons were extracted
from Mac OS 9 resource files by a third party and converted to PNG. The MIT
license file does not establish the rights to Apple's original icon artwork;
those rights are unresolved here. These assets are included as a historically
faithful visual reference, with attribution to the repository and its stated
source process.
