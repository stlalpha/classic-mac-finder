# Macintosh Human Interface Guidelines

These Apple-authored references are saved here for local UI research:

- `Macintosh Human Interface Guidelines (1996).pdf` — the complete 410-page baseline guide.
- `Mac OS 8 Human Interface Guidelines (1997 supplement).pdf` — the 142-page supplement on the Platinum appearance and Appearance Manager. Apple describes this as an addendum; it does not replace the baseline guide.

Source: [Inside Macintosh documentation archive](https://dev.os9.ca/techpubs/mac/). Both PDFs are copyright Apple Computer, Inc. and are included here as local reference material.
